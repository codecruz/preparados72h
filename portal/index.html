                  Código Morse

                  Para pedir ayuda o comunicarte sin voz ni cobertura: con linterna, silbato, golpes o la pantalla del móvil. Funciona sin conexión.

                  SOS se emite seguido, sin pausa entre letras, y se repite. Con «Luz», la pantalla parpadea a pantalla completa (como mucho 2,5 veces por segundo): tócala o pulsa Esc para parar. Si tú o alguien cerca tiene epilepsia fotosensible, usa sonido o vibración. Gasta batería: úsala cuando alguien pueda verte.

                  Puntos y rayas; un espacio entre letras y «/» entre palabras.

                  Tiempos

                  • · punto = 1 tiempo
                  • — raya = 3 tiempos
                  • entre señales de una letra = 1
                  • entre letras = 3
                  • entre palabras = 7
